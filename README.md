# Algo-Arena
My take on making DSA a little more interesting with interactive algorithm visualizations.

Algorithm Arena is a pathfinding visualizer I started building after learning DSA this semester. I wanted to actually *see* how algorithms explore a graph instead of just understanding them theoretically.

### What it does

- **BFS** — explores the grid level by level.
- **DFS** — explores one path as far as possible before backtracking.
- **Dijkstra's Algorithm** — finds the shortest path while accounting for terrain costs.
- **Walls** — manually add obstacles to block paths.
- **Mud** — add weighted terrain that makes traversal more expensive.
